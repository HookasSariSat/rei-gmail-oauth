プライバシーポリシー

Rei は開発者本人だけが使う個人用のアシスタントで、利用者は開発者本人だけです。

扱うデータ

  • Gmail API(gmail.modify)で、開発者本人のGmailの受信メールの送信元・件名・冒頭の短い抜粋・ラベルを読みます。本文は読みません。
  • 本人の承認に基づいて、受信トレイから外す(アーカイブ)・ラベルを作って付ける操作をします。メールの送信・削除はしません。

保存と共有

  • データは開発者本人の端末で処理し、売却・広告への利用・第三者への提供はしません。
  • 仕分けの判断のため、送信元・件名などを開発者本人が契約しているAIサービス(Anthropic の Claude)に渡すことがあります。
  • Google のユーザーデータの扱いは Google API Services User Data Policy(Limited Use の要件を含む)に従います。

アクセスの取り消し

Google アカウントの「セキュリティ」→「サードパーティのアクセス」からいつでも取り消せます。

GitHub の Issue

Rei is used only by its developer. It reads sender, subject, a short snippet and labels of the developer's own Gmail messages, archives or labels them with the developer's approval, never sends or deletes mail, and never sells or shares the data. Sender and subject may be passed to Anthropic's Claude for triage. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
